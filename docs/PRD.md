# 趣玩岛（Funme）产品需求文档 v1.0

## 1. 产品定位

- **一句话**：给 4–12 岁孩子的卡通小游戏合集，经典棋类 + 热门益智 + 手速反应，一个 App 全都有。
- **平台优先级**：HarmonyOS NEXT ≈ iOS ≈ Android（同一套 Flutter 代码） > iPad / 鸿蒙平板 > Web（后置，仅用于预览与测试）。
- **核心原则**：
  1. **离线、零广告、零内购、零数据收集**：孩子拿到就能玩，家长放心。
  2. **卡通 + 动效**：每一次点击都有回弹、音效、震动；赢了有彩带、星星和吉祥物欢呼。
  3. **规则易懂**：每个游戏都有图文规则、走法提示、悔棋；输了也只给鼓励。
  4. **单机可对战**：人机（三档难度）与同屏双人；飞行棋、跳棋支持 2–4/6 人混合人机。

## 2. 目标用户

| 角色 | 诉求 | 设计响应 |
| --- | --- | --- |
| 4–6 岁 | 看不懂字、手指不精准 | 大按钮（≥56dp）、颜色+形状双重区分、音效引导、井字棋/记忆翻牌/打地鼠等低门槛游戏 |
| 7–12 岁 | 想挑战、想赢大人 | 象棋/军棋/跳棋/五子棋人机三档难度、最佳纪录、星星收集 |
| 家长 | 控制时长、无广告、安全 | 家长中心（算术门锁）、护眼时长提醒、隐私说明、完全离线 |

## 3. 游戏阵容（18 款）

### 3.1 棋类对战（9）

| 游戏 | 模式 | 关键规则 / 亮点 |
| --- | --- | --- |
| 飞行棋 | 2–4 人，每席可选玩家/电脑 | 掷 1/3/6 起飞到箭头待进区、掷 5 直接飞到跑道第 7 格，起飞后需等下一次掷骰才能走；掷 6（含起飞）再掷一次，连续三个 6 作废并将最远的飞机罚回机库；同色格跳跃、飞行格飞越；撞子送回机库；终点需点数刚好，多出倒退。骰子翻滚、飞机逐格跳跃与飞越动画 |
| 五子棋 | 人机（三档）/ 双人 | 15×15，先连五子获胜；落子弹跳、胜利连线闪光；悔棋、提示 |
| 跳棋 | 2/3/4/6 人，混合人机 | 标准六角星 121 孔；单步或连跳；全部棋子到对角营地获胜；连跳路径逐跳动画 |
| 象棋 | 人机（三档）/ 双人 | 完整规则（蹩马腿、塞象眼、炮架、将帅不照面），将军提示、困毙判负、60 回合无吃子判和；AI 在后台 Isolate 运算 |
| 军棋（翻翻棋） | 人机 / 双人 | 标准 5×12 棋盘、铁路/公路/行营；50 子暗置，先翻定色；工兵铁路转弯、炸弹同归于尽、地雷只有工兵能挖；扛到对方军旗获胜 |
| 斗兽棋 | 人机（三档）/ 双人 | 象狮虎豹狼狗猫鼠；鼠可下河、鼠吃象；狮虎跳河；陷阱、兽穴。卡通动物棋子 |
| 黑白棋 | 人机（三档）/ 双人 | 8×8，可落点提示，翻转 3D 动画 |
| 四子棋 | 人机（三档）/ 双人 | 7×6，棋子下落弹跳动画，连成四子获胜 |
| 井字棋 | 人机（三档）/ 双人 | 最适合低龄的入门棋，困难档为完美 AI |

### 3.2 益智烧脑（6）

| 游戏 | 关键规则 / 亮点 |
| --- | --- |
| 记忆翻牌 | 卡通动物配对，3 个难度（2×3 / 3×4 / 4×5），翻牌 3D 动画，按步数评星 |
| 彩球排序 | 时下最热门的 Sort 品类：把同色彩球放进同一根管子；关卡由求解器验证必然有解，无限关卡 |
| 方块消消 | Block Blast 玩法：8×8 棋盘拖放方块，整行/整列消除，连击加分 |
| 数字华容道 | 3×3 / 4×4 / 5×5，随机打乱保证有解，计时+步数纪录 |
| 2048 | 滑动合并，卡通色块，最高分纪录 |
| 扫雷 | 儿童友好版：首点必安全，插旗模式按钮，三档大小 |

### 3.3 手速反应（3）

| 游戏 | 关键规则 / 亮点 |
| --- | --- |
| 贪吃蛇 | 滑动/方向键控制，卡通蛇与水果，速度随长度递增，可选穿墙模式 |
| 打地鼠 | 60 秒，地鼠/金地鼠/小兔子（别打！），连击加成 |
| 小鸟飞飞 | 点击振翅穿过树丛，最高分纪录 |

> 调研依据：2026 上半年混合休闲益智收入由 Sort（排序）、Screw（拧螺丝）、Block（方块）三大品类主导，三消与合成紧随其后；儿童向推荐中拼图、连线、数独、记忆类常见。v1.0 选取其中对儿童最友好、规则最直观的 Sort / Block / 合成（2048）/ 记忆。拧螺丝、连线、数独列入 v1.1 候选。

## 4. 通用体验

### 4.1 首页
- 顶部：吉祥物「豆豆」+ 问候语（按时段变化）+ 星星总数 + 家长中心入口。
- 分类页签：全部 / 棋类对战 / 益智烧脑 / 手速反应。
- 游戏卡片：每款游戏独立配色与手绘图标、空闲时轻微浮动；进入时交错弹出。
- 背景：渐变天空 + 漂浮云朵 + 气泡。

### 4.2 对局流程
1. 点卡片 → 弹出「开局设置」（模式 / 难度 / 席位，记住上次选择）。
2. 对局页：顶栏（返回、标题、规则、重开）+ 回合提示 + 棋盘 + 底部操作（悔棋、提示等）。
3. 结束 → 结算层：胜利彩带 + 星星（1–3 颗）+ 吉祥物动作；失败显示「差一点点！」鼓励；按钮「再来一局 / 返回首页」。

### 4.3 星星规则
- 人机胜利：简单 1★ / 普通 2★ / 困难 3★；双人对战不计星。
- 益智/反应类：按步数、用时或分数评 1–3★。
- 每款游戏记录最佳星级与最佳成绩，首页汇总总星数。

### 4.4 家长中心（算术门锁进入）
- 音效 / 背景音乐 / 震动 开关。
- 护眼提醒：关 / 15 / 20 / 30 / 45 / 60 分钟；到点出现「休息一下眼睛吧」，家长解锁才能继续。
- 隐私说明：不联网、不收集任何个人信息、不含广告与内购。
- 清除游戏记录（二次确认）。

## 5. 非功能需求
- 性能：常规场景 60fps（支持高刷设备）；AI 思考放入后台 Isolate，困难档思考时间 ≤ 1.5s。
- 包体：音效为本地合成短音频，总量控制在 2MB 内。
- 适配：手机竖屏为主，平板/折叠屏自适应（棋盘按可用空间等比缩放，横屏时侧栏显示信息）。
- 兼容：鸿蒙端使用 openharmony-sig 维护的插件分支；禁止使用 `Color.withValues`、`CardThemeData` 等 Flutter-OH 不兼容 API。

## 6. 版本规划
- **v1.0**：本文档全部 18 款游戏 + 首页 + 家长中心 + 音效。
- **v1.1 候选**：拧螺丝、宝宝连线、儿童数独（4×4 动物版）、语音播报、主题皮肤、卡通字体。
- **v2.0 候选**：局域网/近场双机对战（鸿蒙分布式能力）、每日挑战。
